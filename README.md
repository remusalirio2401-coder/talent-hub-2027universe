# Talent Hub Universe — despliegue en Vercel

La página de inicio está en la raíz del proyecto: `index.html`.

## Vercel
1. Descomprime este ZIP.
2. Sube **los archivos dentro de esta carpeta** a la raíz de un repositorio de GitHub (no una carpeta contenedora).
3. En Vercel importa el repositorio.
4. Framework Preset: **Other**.
5. Root Directory: **./** (raíz).
6. Build Command: dejar vacío / Override desactivado.
7. Output Directory: dejar vacío / Override desactivado.
8. Deploy.

Si tu proyecto existente tiene Root Directory configurada a una subcarpeta, cámbiala a `./`.

Contenido: prototipo demostrativo. Revisar métricas y autorizaciones de publicación antes de uso corporativo.
